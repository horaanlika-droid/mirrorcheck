# PRICELEX — агентство криптоброкеров (BTC & GRAM)

PRICELEX — не просто обменник, а агентство брокеров, которые в реальном времени
находят лучшие варианты на рынке. Telegram Web App + бот оператора.
Функциональность сохранена: калькулятор курса, заявки, выдача реквизитов,
подтверждение оплаты, PDF-чек, история, реферальная программа и чат поддержки.

Интерфейс — Cinematic Editorial Tech: глубокий графит, монохромные сканы купюр
и бруталистская архитектура (`public/img/`), швейцарская типографика
(Inter Tight + JetBrains Mono), тонкое стекло и янтарный свет, зерно и виньетка.

Курс на главном экране живой: официальный курс обновляется каждые 10 секунд,
график строится только по фактическим наблюдениям (`GET /api/rates/history`),
точки пишутся при каждом автообновлении курса. Пока история не накопилась,
приложение честно показывает текущий курс и подсказку вместо нарисованной от руки
кривой. Самая низкая точка окна отмечается на графике как «просадка», а когда
текущий курс у минимума периода, под графиком появляется сигнал «Лучшее время для
покупки». Токены, компоненты и состояния описаны в [`DESIGN.md`](DESIGN.md).

## Запуск

```bash
npm ci
cp .env.example .env
# укажи BOT_TOKEN и ADMIN_ID в .env
npm start
```

Точка входа для BotHost — `index.js` (также работают `server.js` и `bot.js`).
Сервер слушает `SERVER_PORT`, затем `PORT`, а если переменные не заданы — порт
`8080`. Хост должен проксировать его на `0.0.0.0`.

Telegram Mini App требует HTTPS. Адрес приложения определяется автоматически и
используется только для кнопки меню бота — нигде не показывается и не рассылается.
При необходимости его можно задать вручную:

```env
BOT_TOKEN=1234567890:AA...
ADMIN_ID=123456789
PUBLIC_URL=https://pricelex.example
```

Если `BOT_TOKEN` не задан, приложение запускается в демо-режиме без Telegram-бота;
операторские действия доступны через демо-панель в интерфейсе.

## Возможности

- обмен RUB → BTC/GRAM с пересчётом в обе стороны;
- график курса по реальной истории обновлений и сводка объёма в истории обменов;
- статусы заявки: поиск реквизитов, ожидание оплаты, подтверждение и завершение;
- управление заявками и настройками через Telegram-бота;
- загрузка PDF-чека и передача его оператору;
- история операций, реферальная ссылка и чат поддержки внутри приложения;
- «Стать брокером» в разделе «Инфо»: кандидат рассказывает про опыт и оставляет
  контакт, заявка приходит администрации в бота; правила площадки (гарантийный
  счёт, разморозка после проверки платежа) опубликованы там же;
- отзывы: клиент может оставить отзыв только после завершённого обмена (один на
  заявку). Автор сразу видит свой отзыв опубликованным и о модерации не знает,
  остальным отзыв виден только после одобрения оператором;
- в боте (`⭐ Отзывы`, `/reviews`): модерация, добавление своих отзывов и
  редактирование любого — имя, оценка, текст, дата и время (по Москве, UTC+3);
- HMAC-проверка Telegram `initData` и разграничение прав операторов;
- JSON-база в `data/db.json`, сохраняемая между перезапусками.

## Брокеры площадки

Площадка работает как аренда опыта брокера: брокер ведёт сделку клиента через
гарантийный счёт, администрация проверяет платёж и размораживает средства для
покупателя. Доступ строго ручной — логин и пароль регулируются в админ-панели:

```
/addbroker логин пароль Имя   — выдать доступ брокера
/brokerpass логин новыйпароль — сменить пароль
/delbroker логин              — отозвать доступ
/brokers                      — заявки кандидатов, аккаунты, выплаты
```

Брокер входит в свою панель командой `/broker` в том же боте (логин + пароль,
Telegram привязывается при первом входе, «⏏ Выйти» отвязывает). В панели:
список активных заявок, выдача реквизитов гарантийного счёта, подтверждение
оплаты с начислением вознаграждения (`brokerPercent`, по умолчанию 10 % от
крипто-суммы сделки, настраивается в «⚙️ Настройки»), баланс и вывод.

Выплата брокеру — по его запросу в любое время через бота при балансе от
`0.0002 BTC`: администрация получает уведомление с адресом, переводит средства
и отмечает выплату, брокер получает подтверждение.
