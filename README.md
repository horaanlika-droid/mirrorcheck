# Pricelex Worldwide — обмен подарочных карт на BTC

Pricelex Worldwide принимает подарочные карты **Google Play, iTunes, Xbox и Apple Store** региона США с номиналом в USD и выплачивает BTC на Bitcoin-кошелёк. Клиент задаёт только номинал карты; ориентировочная выплата показывается в BTC по прямому курсу BTC/USD. Фиатных выплат и рублёвых расчётов в пользовательском сценарии нет.

Клиентский поток сохранён от VEGA: создание заявки → подключение оператора → отправка кода карты только после запроса оператора → проверка карты → выплата BTC. Web App работает в Telegram и в обычном браузере; оператор управляет заявками через Telegram-бота и встроенную демо-панель.

## Бренд и интерфейс

Название и оформление — Pricelex Worldwide: глубокий чёрный фон без фоновых изображений, бирюзовые световые акценты и тонкие холодные границы панелей. В интерфейсе — крупный первый экран, орбитальная композиция из поддерживаемых логотипов, карточки направлений и пошаговая форма. Палитра и адаптивные компоненты находятся в `public/style.css`, разметка и поведение — в `public/index.html` и `public/app.js`.

Язык: всё, что видит клиент (Mini App, клиентский бот, виджеты), и панель оператора — на русском. «Отзывы» в приложении: отзыв можно оставить только после завершённой сделки либо добавить вручную через админку.

## Запуск

```bash
npm ci
cp .env.example .env
# задать BOT_TOKEN и ADMIN_ID в .env
npm start
```

Сервер слушает `SERVER_PORT`, затем `PORT`, либо порт `8080` по умолчанию; привязывается к `0.0.0.0`. Telegram Mini App требует HTTPS. При необходимости укажите публичный адрес:

```env
BOT_TOKEN=1234567890:AA...
ADMIN_ID=123456789
PUBLIC_URL=https://pricelex.example
```

Без `BOT_TOKEN` запускается демо-режим, включая панель оператора в приложении.

## Механика

- Поддерживаемые направления: Google Gift Card, iTunes Gift Card, Xbox Gift Card и Apple Store Gift Card (только регион США, валюта USD) → BTC.
- **У каждой карты свой курс.** Для каждого бренда в настройках хранится своя скидка к споту (`settings.cardFees[ключ]`, 0–50 %) и свой итоговый курс выплаты (`settings.cardRates[ключ]`, BTC за $1 номинала). Клиент видит курс каждой карты отдельно — в витрине, в форме, в боте и в виджете; скидку видит только оператор.
- Оператор меняет курс любой карты независимо от остальных: в админке приложения (четыре поля скидок с предпросмотром выплаты за $10), в боте оператора (⚙️ Настройки → отдельная кнопка на каждую карту) или через `POST /api/admin/settings` с `cardFees: { GOOGLE_USD: 5, ... }`. Старое поле `giftPercent` по-прежнему принимается и задаёт одну скидку сразу для всех карт; при загрузке старой базы общая комиссия и общий курс автоматически раскладываются на отдельные настройки карт.
- Минимальный номинал — $10, шаг — $10. Выплата считается как USD-номинал × курс выбранной карты, округление — вниз до сатоши.
- Спот BTC/USD берётся из нескольких публичных источников (CoinGecko, Kraken, Coinbase и Binance): используется медиана доступных котировок, недоступные источники не мешают остальным. Курс каждой карты = спот × (1 − её скидка / 100).
- Спот обновляется каждые пять минут; при обновлении пересчитываются курсы всех карт с сохранением их индивидуальных скидок. Можно отключить автообновление через `RATES_DISABLED=1` или задать свой интервал `RATES_INTERVAL_MS` (миллисекунды).
- Где и по какому курсу клиент купил карту — сервису не важно: чек и цену покупки мы не спрашиваем. Важно только, чтобы карта работала: регион США, номинал в USD, полный неиспользованный баланс. Эта формулировка используется в приложении, в клиентском боте и в `CARD_INFO_NOTE` (`src/currencies.js`).
- Клиент указывает Bitcoin-адрес, затем создаёт заявку. Код карты нельзя отправить до подключения оператора. После команды оператора клиент вводит код в приложении, оператор проверяет карту и подтверждает выплату.
- Заявка действует один час. Статус обновляется в Web App; история, чат поддержки и вкладка «Отзывы» доступны в приложении. Реферальная ссылка живёт в профиле и во вкладке «Отзывы».
- Отзыв можно оставить после завершённой сделки (один на заявку) или добавить/удалить вручную через админку в приложении; витрина показывает среднюю оценку и последние отзывы.
- Администратор может включать отдельные направления, задавать скидку/курс для каждой карты по отдельности и менять ссылку на поддержку в операторской панели или боте.
- Заявки и настройки хранятся в JSON-базе `data/db.json`.
