# PRICELEX — обмен подарочных карт на BTC

PRICELEX принимает подарочные карты **Google Play, iTunes, Xbox и Apple Store** региона США с номиналом в USD и выплачивает BTC на Bitcoin-кошелёк. Клиент задаёт только номинал карты; ориентировочная выплата показывается в BTC по прямому курсу BTC/USD. Фиатных выплат и рублёвых расчётов в пользовательском сценарии нет.

Клиентский поток сохранён от VEGA: создание заявки → подключение оператора → отправка кода карты только после запроса оператора → проверка карты → выплата BTC. Web App работает в Telegram и в обычном браузере; оператор управляет заявками через Telegram-бота и встроенную демо-панель.

## Бренд и интерфейс

Название и оформление — PRICELEX: глубокий чёрный фон без фоновых изображений, бирюзовые световые акценты и тонкие холодные границы панелей. В интерфейсе — крупный первый экран, орбитальная композиция из поддерживаемых логотипов, карточки направлений и пошаговая форма. Палитра и адаптивные компоненты находятся в `public/style.css`, разметка и поведение — в `public/index.html` и `public/app.js`.

## Запуск

```bash
npm ci
cp .env.example .env
# задать BOT_TOKEN и ADMIN_ID в .env
npm start
```

Сервер слушает `SERVER_PORT`, затем `PORT`, либо порт `8080` по умолчанию; привязывается к `0.0.0.0`. Telegram Mini App требует HTTPS. При необходимости укажите публичный адрес:

```env
BOT_TOKEN=1234567890:AA...
ADMIN_ID=123456789
PUBLIC_URL=https://pricelex.example
```

Без `BOT_TOKEN` запускается демо-режим, включая панель оператора в приложении.

## Механика

- Поддерживаемые направления: Google Gift Card, iTunes Gift Card, Xbox Gift Card и Apple Store Gift Card (только регион США, валюта USD) → BTC.
- Минимальный номинал — $10, шаг — $10. Выплата считается как USD-номинал × BTC за $1, округление — вниз до сатоши.
- Курс карты строится по прямому BTC/USD споту из нескольких публичных источников (CoinGecko, Kraken, Coinbase и Binance) и настраиваемой комиссии. Используется медиана доступных котировок; внешние источники, которые временно недоступны, не мешают остальным.
- Курс обновляется каждые пять минут. Можно отключить автообновление через `RATES_DISABLED=1` или задать свой интервал `RATES_INTERVAL_MS` (миллисекунды).
- Клиент указывает Bitcoin-адрес, затем создаёт заявку. Код карты нельзя отправить до подключения оператора. После команды оператора клиент вводит код в приложении, оператор проверяет карту и подтверждает выплату.
- Заявка действует один час. Статус обновляется в Web App; история, чат поддержки, отзывы и реферальная ссылка доступны в приложении.
- Отзывы: клиент оставляет отзыв только после завершённой сделки (одна оценка 1–5 и текст на заявку), оператор добавляет и удаляет отзывы в админке приложения или в боте (⭐ Отзывы). Реферальная ссылка живёт на вкладке «Отзывы».
- Администратор может включать отдельные направления, менять комиссию и ссылку на поддержку в операторской панели или боте.
- Заявки и настройки хранятся в JSON-базе `data/db.json`.
