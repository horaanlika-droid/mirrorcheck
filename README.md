# PRICELEX — мануальный обменник BTC & GRAM

PRICELEX — Telegram Web App для ручного обмена BTC/GRAM с операторским ботом.
Функциональность сохранена: калькулятор курса, заявки, выдача реквизитов,
подтверждение оплаты, PDF-чек, история, реферальная программа и чат поддержки.

Интерфейс переработан в стиле раннего Apple: светлое стекло, мягкие голубые
градиенты, полупрозрачные панели, металлические кнопки и системная типографика.

## Запуск

```bash
npm ci
cp .env.example .env
# укажи BOT_TOKEN и ADMIN_ID в .env
npm start
```

Точка входа для BotHost — `index.js` (также работают `server.js` и `bot.js`).
Сервер слушает `SERVER_PORT`, затем `PORT`, а если переменные не заданы — порт
`8080`. Хост должен проксировать его на `0.0.0.0`.

Telegram Mini App требует HTTPS. Можно задать публичный адрес вручную:

```env
BOT_TOKEN=1234567890:AA...
ADMIN_ID=123456789
PUBLIC_URL=https://pricelex.example
```

Если `BOT_TOKEN` не задан, приложение запускается в демо-режиме без Telegram-бота;
операторские действия доступны через демо-панель в интерфейсе.

## Возможности

- обмен RUB → BTC/GRAM с пересчётом в обе стороны;
- статусы заявки: поиск реквизитов, ожидание оплаты, подтверждение и завершение;
- управление заявками и настройками через Telegram-бота;
- загрузка PDF-чека и передача его оператору;
- история операций, реферальная ссылка и чат поддержки;
- HMAC-проверка Telegram `initData` и разграничение прав операторов;
- JSON-база в `data/db.json`, сохраняемая между перезапусками.
