# mirrorcheck

Учебное зеркало для локального тестового стенда. Telegram-команда сохраняет
тестовую `http`/`https`-ссылку, а веб-страница открывает её в sandboxed iframe.
Верхняя белая полоса высотой `1/20` экрана содержит фразу
**«вот так работает зеркало»**.

## Запуск

```bash
BOT_TOKEN="токен_бота" \
PUBLIC_BASE_URL="https://твой-домен.example" \
python3 main.py
```

Приложение слушает `0.0.0.0` и порт из переменной `PORT` (по умолчанию `3000`),
поэтому его можно использовать на BotHost. Для ограничения доступа укажи ID
чатов через `BOT_ALLOWED_CHAT_IDS`:

```bash
BOT_ALLOWED_CHAT_IDS="123456789,-1009876543210" python3 main.py
```

Без `BOT_TOKEN` веб-часть всё равно запускается, что удобно для локального
просмотра интерфейса.

## Команды бота

- `/mirror https://example.test/page` — установить любую тестовую ссылку;
- `/show` — показать установленную ссылку и адрес зеркала;
- `/clear` — очистить зеркало;
- `/help` — показать справку.

Команда принимает только `http://` и `https://` без логина и пароля в URL.
Сервер не скачивает сайты и не выступает открытым reverse proxy: браузер
открывает установленную ссылку напрямую внутри sandboxed iframe. Поэтому сайт,
который запрещает встраивание через `X-Frame-Options` или CSP, может не
отобразиться — это ограничение самого тестового стенда.
