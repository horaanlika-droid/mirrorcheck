# PRICELEX — визуальная система OBSIDIAN

Документ описывает дизайн-язык клиента (`public/index.html`, `public/style.css`,
`public/app.js`). Референсы: приборная панель Mercedes AMG в полной комплектации,
Porsche-минимализм, ночные люксовые крипто-дашборды (стеклянные карточки,
свечение кривых, крупные серифные цифры).

## Формула

**Чёрное обсидиан-стекло + шампанское золото + приборная точность.**

| Приём | Как реализовано |
| --- | --- |
| Почти чёрный фон с инженерной сеткой | `.bg::before` — чертёжная сетка 56px, проявляется к верху; `.bg::after` — виньетка + плёночное зерно |
| Тёплое золотое свечение на горизонте | `.glowline` + `.orb-a` (золото) и `.orb-b` (холодная сталь), медленный дрейф, отключается в `prefers-reduced-motion` |
| Обсидиановые карточки с золотым хайрлайном | `.card`: стекло + белая 1px окантовка + `inset` блик; `.card::after` — золотая волосяная линия сверху |
| Крупные серифные числа | `.metric`, `.pay-amount .v`, `.ref-stat .v` — serif, `tabular-nums`, шампанское свечение |
| Золотая кривая графика с ореолом | `renderChart()`: градиент `#8a6a2f → #d8b46a → #fff1cc`, `drop-shadow` на линии, ядро точки `#fff6e0` |
| Стеклянные pill / сегменты / кнопки | `.pill`, `.seg`, `.btn-primary` — золото с бликом, `:active`-сжатие и HapticFeedback |
| Приборные статусы | изумруд `--ok` (готово), янтарь `--warn` (ожидание), рубин `--danger` (отказ) — только как микросигналы, основной акцент один: золото |

## Токены

```
--bg: #050506        фон (обсидиан)
--gold: #d4af6a      основной акцент      --gold-2: #f0dca4  светлый шампанк
--gold-3: #8a6a2f    тёмное золото        --champagne: #f2e7cd  тёплый текст
--ice: #a8c1dd       холодная сталь (вторичные данные, ссылки на блокчейн)
--txt: #f4f4f2       основной текст       --mut: #8f939b   подписи
--ok: #3ddba6        завершено            --warn: #e8b45c  ожидание
--danger: #e5637f    отклонено            --dim: #63666d   самый тихий текст
```

Радиусы `28 / 22 / 16 / 12 px`, тень `--shadow`, шрифт — системный стек
(`-apple-system`, SF Pro, Inter) + serif-стек (Bodoni 72 / Didot → Georgia)
для крупных чисел и заголовков. Внешние шрифты не грузятся: Telegram Mini App
должен открываться мгновенно.

## Экраны

- **Обмен** — герой-карточка: монолит под стеклом, сегмент BTC/GRAM, серифный
  курс, золотая кривая по фактическим наблюдениям, сигнал «Лучшее время для
  покупки»; ниже — форма суммы и кошелёк.
- **История** — сводка объёма, золотой график по завершённым заявкам, фильтр
  «Все / Завершённые», список операций с чипами статусов.
- **Рефералы** — серифные метрики, шаги программы.
- **Отзывы** — кадр с рейтингом, форма (только по завершённым обменам), лента.
- **Помощь** — чат с брокером + прямая ссылка на @stonym0ntana; свои сообщения —
  тёмное золото-стекло.
- **Инфо** — «Слово PRICELEX»: речь основателя дословно, строки проявляются по
  очереди на фоне золотых потоков (`.sp-line`, serif, ключевые фразы — золотым
  курсивом). Комиссия на клиентских экранах не упоминается.

## Принцип честных данных

График курса рисуется **только по реальным точкам** (`GET /api/rates/history`).
Точка добавляется при каждом успешном автообновлении курса или смене курса
оператором. Пока история меньше трёх точек, приложение не рисует выдуманную
кривую: показывает текущий курс, направляющую и подсказку.

Просадка — это минимальная **фактическая** точка окна: на графике она отмечена
изумрудным ромбом, пунктиром и подписью с ценой и временем. Сигнал под графиком:
«Лучшее время для покупки» — курс в нижних 20 % диапазона периода; «Курс ниже
среднего» — ниже среднего значения; иначе — нейтральная подсказка с лучшей ценой
периода. Под сигналом всегда мелкая приписка: «По фактическим данным курса за
период. Не является инвестиционной рекомендацией.»

## Состояния и доступность

- Статусы заявок: `new → details → paid → completed / rejected / cancelled`
  (`.chip.<status>`), финальные статусы не имеют активных действий.
- Все интерактивные элементы имеют состояние `:active` (лёгкое сжатие) и
  вибрацию Telegram (`HapticFeedback`).
- `prefers-reduced-motion` отключает дрейф орбов, кольца спиннера, проявление
  строк речи и анимации переходов.
- Декор помечен `aria-hidden`, статус связи — `role="status"`.
