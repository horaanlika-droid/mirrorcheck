# PRICELEX — визуальная система CINEMATIC EDITORIAL TECH

Документ описывает дизайн-язык клиента (`public/index.html`, `public/style.css`,
`public/app.js`). Направление: **luxury digital interface** — editorial brutalism,
кинематографичная монохромная фотография, швейцарская типографика, тонкое
стекло и свет дорогого физического прибора. Интерфейс живёт между luxury product
page, contemporary art website и futuristic hardware control system.

## Формула

**Глубокий графит + монохромные сканы купюр + тонкий янтарный свет + grotesk/mono.**

| Приём | Как реализовано |
| --- | --- |
| Почти чёрный графитовый мир | `--bg-0…--bg-5`: `#080808 → #343430`; фон — затемнённый размытый кадр `.bg-img` (микро-параллакс через `--sy`), инженерная сетка 72px `.bg-grid`, виньетка `.bg-veil`, плёночное зерно `.bg::after` (blend overlay) |
| Янтарь только как атмосфера | `#D97838 / #E89552 / #F2B06C` — маркеры, active-состояния, glow, thin highlights; один слабый дрейфующий свет `.bg-glow` |
| Кинематографичная съёмка | макро-сканы купюр (гравюра) и бруталистская архитектура под маской `linear-gradient` — UI лежит поверх изображения |
| Swiss typography | `Inter Tight` (display −0.035em, заголовки −0.02em) + `JetBrains Mono` для metadata, координат, реквизитов, axis, чипов; micro-labels 8–10px uppercase ls 0.22–0.34em |
| Cinematic glassmorphism | карточки: стекло `blur(24px)` + 1px `rgba(255,255,255,.08)` + inset-блик + верхняя волосяная линия + тёплый осколок света в углу |
| Editorial-компоновка | крупные радиусы только у floating panels (`--r-panel: 30px`), второстепенные блоки строже (14–18px); угловые засечки кадра `.hero-frame`; hairline-разделители; mono-ось с тиками |
| Hardware controls | круглые индикаторы валют `.coin-ic`, круглый send, pill-сегменты, тонкие outlined ghost-кнопки, янтарный outlined primary без заливки |
| Кинематографичный motion | slow fade + blur transitions (`.view` 0.6s), `sp-in` для речи, gentle glow, sweep-прогресс 2.4s; `prefers-reduced-motion` выключает всё |

## Кадры (`public/img/`)

AI-генерация + доводка сканов купюр из архива проекта, суммарно < 1 МБ:

- `hero.jpg` — макро-скан купюры (гравюрный портрет), янтарный скользящий свет:
  герой-карточка курса (`.hero-art`, маска уходит в графит) + preload;
- `broker.jpg` — гравюрный «глаз» купюры с янтарным rim-light: этап «подбор
  реквизитов» (`.stage-art`) — метафора внимания брокера;
- `tower.jpg` — бруталистская башня со швом света: сводка объёма в истории
  (`.hist-art`);
- `speech.jpg` — луч света в бетонном зале: фон речи на вкладке «Инфо» (`.sp-art`);
- `reputation.jpg` — чёрный мрамор с янтарными жилами: герой отзывов (`.ed-art`);
- `ambient.jpg` — почти чёрные панели с тёплым углом: размытый фон страницы.

```
--bg-0: #080808  --bg-1: #0A0A09  --bg-2: #111110  --bg-3: #181817
--bg-4: #252523  --bg-5: #343430
--ink:  #F2F1ED  --txt-2: #B8B7B1  --mut: #77766F  --dim: #55544F
--amber:  #D97838   --amber-2: #E89552   --amber-3: #F2B06C
--line: rgba(255,255,255,.10)  --line-2: rgba(255,255,255,.16)
микросигналы: --ok #5FBA97 · --warn #E89552 · --steel #9AA5B3 · --danger #D36A70
```

Радиусы `30 / 18 / 14 / 12 px`, easing `--ease-o: cubic-bezier(.22,.75,.18,1)`.
Шрифты — `Inter Tight` (display/body) и `JetBrains Mono` (technical) с системным
fallback; загрузка не блокирует первый рендер (`display=swap`).

## Экраны

- **Обмен** — hero-panel: скан купюры под стеклом, засечки кадра, display-курс,
  янтарная кривая по фактическим наблюдениям, mono-ось, сигнал «Лучшее время
  для покупки»; ниже — форма суммы и кошелёк на более строгих блоках.
- **История** — башня над сводкой объёма, график по завершённым заявкам, фильтр
  «Все / Завершённые», список операций с чипами статусов.
- **Рефералы** — display-метрики, шаги с круглыми маркерами.
- **Отзывы** — мраморный кадр с рейтингом, форма (только по завершённым
  обменам), лента.
- **Помощь** — чат с брокером; свои сообщения — тёплый янтарный градиент-стекло.
- **Инфо** — «Слово PRICELEX»: речь основателя дословно, строки проявляются по
  очереди на фоне луча света (`.sp-line`, ключевые фразы — янтарным курсивом).
  Комиссия на клиентских экранах не упоминается.

## Принцип честных данных

График курса рисуется **только по реальным точкам** (`GET /api/rates/history`).
Точка добавляется при каждом успешном автообновлении курса или смене курса
оператором. Пока история меньше трёх точек, приложение не рисует выдуманную
кривую: показывает текущий курс, направляющую и подсказку.

Просадка — минимальная **фактическая** точка окна: на графике она отмечена
шалфейным ромбом, пунктиром и подписью с ценой и временем. Сигнал под графиком:
«Лучшее время для покупки» — курс в нижних 20 % диапазона периода; «Курс ниже
среднего» — ниже среднего значения; иначе — нейтральная подсказка с лучшей
ценой периода. Под сигналом всегда приписка: «По фактическим данным курса за
период. Не является инвестиционной рекомендацией.»

## Состояния и доступность

- Статусы заявок: `new → details → paid → completed / rejected / cancelled`
  (`.chip.<status>` — mono, hairline, микросигнальный цвет), финальные статусы
  не имеют активных действий.
- Все интерактивные элементы имеют тактильный `:active` (лёгкое сжатие) и
  вибрацию Telegram (`HapticFeedback`).
- `prefers-reduced-motion` отключает параллакс, дрейф света, blur-переходы,
  кольца спиннера и проявление строк речи.
- Декор помечен `aria-hidden`, статус связи — `role="status"`.
- На десктопе (≥920px) — вертикальные editorial-подписи по краям вьюпорта.
