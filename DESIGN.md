# PRICELEX — визуальная система Web App

Документ описывает дизайн-язык клиента (`public/index.html`, `public/style.css`,
`public/app.js`) и то, как он соотносится с референсами `IMG_1199–IMG_1201`.

## Основа

| Приём из референса | Как реализовано |
| --- | --- |
| Почти чёрный navy-фон, синие орбы и дуги | `.bg` + `.orb-a/b/c` + `.glowline` (медленный дрейф, отключается в `prefers-reduced-motion`) |
| Glassmorphism: blur, светлая 1px окантовка, верхний блик | `.card`, `.field`, `.nav`, `.toast` (`backdrop-filter`, `inset 0 1px 0 var(--sheen)`) |
| Крупные числа-акценты с плотным трекингом | `.metric`, `.pay-amount .v`, `.ref-stat .v` (`clamp()`, `letter-spacing: -.035em`, `tabular-nums`) |
| Стеклянные pill-элементы и сегмент-контролы | `.pill`, `.ghost-pill`, `.chip`, `.seg` (активный сегмент — синий градиент со свечением) |
| Синяя кривая с маркером и тултипом | `.chart` + SVG из `renderChart()`: `.area`, `.line`, `.dot-halo`, `.dot-core`, `.chart-tip` |
| Большие радиусы и свечение вокруг карточки | `--r-xl: 30px`, `.card-hero` c синим halo-свечением |

## Токены

```
--bg: #04060d      фон приложения
--blue: #2f6bff    основной акцент (градиенты, активные элементы)
--sky: #4ea8ff     светлый акцент, график, ссылки
--ok: #35e0a1      завершённые статусы     --warn: #ffb85c   ожидание
--danger: #ff5f7a  отклонение              --txt: #f2f7ff    основной текст
--mut: #8ba0c2     подписи                 --dim: #5d7196    самый тихий текст
```

Радиусы `30 / 24 / 18 / 13 px`, тень `--shadow`, шрифт — системный стек
(`-apple-system`, SF Pro, Inter). Внешние шрифты не грузятся: Telegram Mini App
должен открываться мгновенно.

## Экраны

- **Обмен** — герой-карточка курса: подпись, сегмент BTC/GRAM, крупный курс,
  pill изменения за окно, график по фактическим наблюдениям, время последнего
  обновления и кнопка «Как это работает»; ниже — форма суммы и кошелёк.
- **История** — сводка объёма обменов с графиком по завершённым заявкам,
  фильтр «Все / Завершённые» и список операций с чипами статусов.
- **Рефералы** — крупные метрики приглашений и бонуса, шаги программы.
- **Чат** — стеклянные пузыри: свои сообщения синим градиентом, поддержка — тёмным стеклом.
- **Инфо** — описание сервиса, «Как это работает», контакты оператора.

## Принцип честных данных

График курса рисуется **только по реальным точкам** (`GET /api/rates/history`).
Точка добавляется при каждом успешном автообновлении курса или смене курса
оператором. Пока история меньше трёх точек, приложение не рисует выдуманную
кривую: показывает текущий курс, направляющую и подсказку.

## Состояния и доступность

- Статусы заявок: `new → details → paid → completed / rejected / cancelled`
  (`.chip.<status>`), финальные статусы не имеют активных действий.
- Все интерактивные элементы имеют состояние `:active` (лёгкое сжатие) и
  вибрацию Telegram (`HapticFeedback`).
- `prefers-reduced-motion` отключает дрейф орбов, кольца спиннера и анимации переходов.
- Декор помечен `aria-hidden`, статус связи — `role="status"`.
